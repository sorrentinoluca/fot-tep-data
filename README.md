# FoT-TEP data archive

Public, versioned storage for data artifacts required to reproduce the FoT-TEP studies.

Each release documents the originating source repository state, archive contents, byte sizes and
SHA-256 digests. Source code, experimental decisions and verification reports remain in
[`sorrentinoluca/fot-phd`](https://github.com/sorrentinoluca/fot-phd).
