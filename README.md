# FoT-TEP data archive

Public, versioned storage for data artifacts used by FoT-TEP studies.

Each study package identifies its manuscript snapshot, cohort, artifact provenance, byte sizes, SHA-256 digests, and reproduction limits. Keep releases for different cohorts and manuscript versions separate; do not replace an earlier cohort when a study is updated.

The 2026 follow-up package is in [`study2_2026/`](study2_2026/README.md). The existing `study2_assets/` files refer to the earlier 96-run cohort. See [`REPRODUCIBILITY.md`](REPRODUCIBILITY.md) for package conventions.
