# FoT-TEP data archive

Public, versioned storage for data artifacts used by FoT-TEP studies.

Each release identifies the study and manuscript version it supports and includes a manifest
with the originating source revision, archive contents, byte sizes and SHA-256 digests. The
source code, experimental specifications and analysis instructions are maintained in the
[FoT-TEP source repository](https://github.com/sorrentinoluca/fot-phd).

Keep data releases for different cohorts and manuscript versions separate. Do not replace or
retag an earlier release when a study is updated. See [REPRODUCIBILITY.md](REPRODUCIBILITY.md)
for the archive structure and the information a release should provide.
